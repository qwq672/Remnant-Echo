Remnant（暂定名）—— Minecraft 原版故事观叙事模组

一个基于 Minecraft 原版碎片化线索构建的完整故事模组。
不魔改原版交互，不脱离官方留白，只通过考古、线索、Boss 与叙事文本，拼凑一支远古文明在三界兴衰的史诗。

🎯 核心原则

1. 不魔改原版交互逻辑：不新增可驯服/骑乘机制，不改变生物 AI、生成、掉落；只通过文本、线索、环境细节赋予故事意义。
2. 贴合原版留白逻辑：不强行填补官方未解释的内容，只做合理串联。
3. 碎片化叙事：玩家在探索中自行拼凑真相，而非线性播片。
4. 三界同源：主世界、下界、末地的建筑与生物源自同一支远古先民文明。
5. 基于官方衍生作品：可参考《Minecraft: Dungeons》《Minecraft: Legends》等官方衍生作中的设定，但以原版为准。

🌍 世界观总览

一、远古先民文明

· 一支掌握维度穿行技术的文明，曾同时开拓主世界、下界、末地。
· 三界遗迹的石砖、楼梯、柱式等砌筑工艺高度一致，仅配色因本地材质而异。
· 文明鼎盛期研究四大领域：
  · 维度穿行（要塞、传送门、末地城）
  · 红石机械（废弃矿井、试炼密室）
  · 灵魂能量（下界要塞、凋灵实验）
  · 生命本源（苍白花园、树脂实验）

二、灾变与分裂

· 凋灵实验失控 → 灵魂扭曲波席卷下界。
· 幽匿实验失控 → 远古城市被侵蚀，监守者诞生。
· 生命树脂实验失控 → 苍白花园白化，嘎枝诞生。
· 文明崩解，三界据点荒废，族群各自演化：

维度 原初分支 现代后裔 演化逻辑
主世界 先民定居者 村民、流浪商人 技术退化，社会延续
下界 先民远征队 猪灵、僵尸猪灵 环境变异，部分开智
末地 末地殖民军 末影人 维度异化，记忆残缺

三、关键种族设定

· 村民：先民主世界后裔，保留农耕、锻造、炼金等古法，避世而居。
· 流浪商人：与村民同源，承袭游走探索遗风，以羊驼为伴。
· 铁傀儡：村民以精铁与刻纹南瓜仿造的古代守卫，守护村落。
· 猪灵：先民下界分支后裔，适应熔岩与灵魂环境，发展出以物易物文明。
· 僵尸猪灵：猪灵进入主世界后因维度能量冲突而退化的不可逆形态。
· 末影人：先民末地分支，因长期食用紫颂果与虚空能量影响而异化，保留跨维度能力但怕水、怕光。
· 骷髅：先民射手阶层遗骨，灵魂被困，执行最后命令。
· 凋灵骷髅：被凋灵能量波抹去灵魂的转化体，活体诅咒。
· 恶魂 / 善魂：下界灵魂生物。善魂为原始温和形态，凋灵战争后多数被污染为恶魂；1.21.11 的“快乐恶魂”是先民维度残留能量与主世界水、低温共同作用下的温和变体。
· 灾厄村民：先民中拒绝接受失败的分支后裔，隐居黑森林，研究禁忌生命合成（恼鬼）与再造神（劫掠兽），与村民为敌。
· 嘎枝：苍白花园生命树脂实验的防御程序回响，核心为嘎枝之心。

🧭 玩家体验流程（推荐顺序）

1. 种子埋下：出生 → 发现村庄新增建筑（考古棚、古老石碑）→ 获得残破笔记。
2. 主世界考古：探索沙漠神殿、丛林神庙、地牢、废弃矿井 → 拼凑先民存在。
3. 下界初探：建造传送门 → 下界堡垒 → 猪灵文明。
4. 下界深处：猪灵堡垒 → 善魂壁画 → 干涸恶魂 → 僵尸猪灵真相。
5. 远古城市：深暗之域 → 幽匿实验失控 → 监守者起源。
6. 苍白花园：黑暗森林 → 生命树脂实验失控 → 嘎枝。
7. 进入末地：要塞 → 认知锁 → 击败末影龙 → 守门人真相。
8. 末地城探索：折跃门 → 末地城/末地船 → 紫珀砖同源证据 → 末影人身份。
9. 末影人的记忆：找到远古日记/记忆水晶 → “被遗忘的士兵”真相。
10. 真结局：收集全部唱片 → 合成 0 号唱片 → 先民领袖遗言。

⚙️ 模组机制（计划）

· 线索书系统：使用 Patchouli 等库实现，随探索自动解锁章节。
· 软性维度锁：末地传送门需玩家“认知达标”（阅读关键线索、探索关键遗迹）才能稳定进入；未达标则出现黑雾与反噬提示，但不强制阻止。
· 村庄建筑：以补充为主（考古棚、古碑、废弃书房），替换不超过 5%（如古井、路灯）。
· 唱片解读：获得唱片时自动在线索书中添加解读页。
· Boss 叙事绑定：凋灵、末影龙等原版 Boss 击杀后触发记忆回放/文本解锁。
· 配乐：监听玩家位置/事件，播放对应原版曲目；不新增音乐文件。
