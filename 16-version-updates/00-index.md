## 🎯 与 Remnant Echo 模组叙事的关联分析

### 高关联（⭐⭐⭐⭐）

#### 1.21.9 铜器时代 — 试炼密室铜质工艺的同源证据

按 [`14-trial-chamber-narrative`](../planning/14-trial-chamber-narrative.md) §6.5"凝灰岩与铜质构件"叙事：试炼密室使用凝灰岩+铜质构件建造，模组解读为"先民在主世界地下深处开采的特殊石材+容易氧化变绿的金属"。

1.21.9 铜器时代的更新（铜盔甲+铜傀儡+铜箱子+模特+铜装饰）**强化了模组"先民铜器工艺"叙事**——铜作为先民鼎盛纪元的核心材料之一，与下界合金（暗红）、紫珀砖（紫）、苍白橡木（白）、青金石（蓝）共同构成模组的"四色光谱+第五色（铜绿）"。

**模组采纳建议**：
- 铜傀儡可解读为"先民尝试制造的下界合金守卫的早期实验"——与"铁傀儡=先民守卫的退化复制品"叙事呼应
- 铜箱子可作为先民储物设施的变体（与试炼密室 Vault 同源）
- 铜盔甲可作为"先民鼎盛期士兵装备"的考古发现

### 中关联（⭐⭐⭐）

#### 26.3 荒野之缚 — 大分裂后流浪者遗迹

按 [`02-story-timeline-plan`](../planning/02-story-timeline-plan.md) §5.5 大分裂设定："三界据点荒废，族群各自演化"。

26.3 新增的"废弃营地"结构（含帐篷+干草床+营火+箱子）**可作为模组"大分裂后流浪者遗迹"叙事载体**——大分裂后，先民后裔（村民/流浪商人/灾厄村民）在荒野中建立的临时营地，废弃后成为今日玩家发现的"废弃营地"。

**模组采纳建议**：
- 废弃营地可作为模组笔记 #16（航海者清单）的获取来源之一
- 帐篷可解读为"流浪商人羊驼队伍的临时住所"
- 干草床可解读为"流浪者不固定出生点的睡觉方式"——与模组玩家"局外人"叙事呼应

#### 26.2 混沌立方 — 先民工业研究遗址

按 [`16-worldview-overview`](../planning/16-worldview-overview.md) §4.2 红石机械研究领域：先民在鼎盛期研究红石机械，废弃矿井+试炼密室是产物。

26.2 新增的"硫磺洞穴"（含硫磺立方体+间歇泉+朱砂）**可作为模组"先民工业研究遗址"叙事载体**——硫磺是工业原料，朱砂是颜料/医药原料，暗示先民曾在地下深处进行大规模工业开采。

**模组采纳建议**：
- 硫磺洞穴可作为模组主世界考古的新遗迹类型（v0.2 后扩展）
- 硫磺立方体可解读为"先民维度能量残留的液态金属生命"（与岩浆怪同源，但主世界版本）
- 朱砂可解读为"先民贵族使用的红色颜料"——与模组"四色光谱"的暗红色对应

### 低关联（⭐⭐）

#### 26.1 微小侵占 — 生命本源研究残留

按 [`02-story-timeline-plan`](../planning/02-story-timeline-plan.md) §5.4 苍白之悔设定：先民研究生命本源（生命树脂实验）。

26.1 新增的"金蒲公英"（喂幼年生物阻止长大）**可作为模组"生命本源研究残留"叙事载体**——金蒲公英是先民生命树脂实验的副产物，能"冻结"生物的成长过程。

**模组采纳建议**：
- 金蒲公英可解读为"苍白花园生命树脂实验的副产物"，散落在主世界
- 幼年生物不老机制可解读为"先民生命本源研究的可控产物"
- 不作为主线必经，作为可选支线叙事

#### 1.21.11 鹦鹉螺更新 — 维度诅咒变体

按 [`02-story-timeline-plan`](../planning/02-story-timeline-plan.md) §5.5 大分裂设定：僵尸猪灵=猪灵进入主世界后的退化形态（维度能量冲突）。

1.21.11 新增的"僵尸鹦鹉螺+骆驼尸壳"**可强化模组"维度诅咒"叙事**——更多不死变体表明原版世界中存在大量"维度异化"产物。

**模组采纳建议**：
- 僵尸鹦鹉螺可解读为"鹦鹉螺进入主世界后的退化形态"（与僵尸猪灵同源）
- 骆驼尸壳可解读为"骆驼在沙漠群系的退化形态"
- 不作为主线必经，作为"维度诅咒"叙事的补充证据

#### 1.21.7 / 1.21.6 — 唱片与音乐

按 [`08-music-disc-unlock-order`](../planning/08-music-disc-unlock-order.md) 22 张原版唱片+0 号唱片叙事：
- 1.21.7 新增 Lava Chicken 唱片——与模组唱片系统直接关联，可作为"先民余响"的新增来源
- 1.21.6 新增 5 首 Amos Roddy 环境音乐——可与模组配乐策略（23 文档 §4）联动，作为新的原版曲目候选

**模组采纳建议**：
- Lava Chicken 唱片加入模组 23 张原版唱片清单（22→23），更新 0 号唱片合成配方
- Amos Roddy 5 首环境音乐加入模组 [`24-design-followups-2`](../planning/24-design-followups-2.md) §Q9 配乐场景清单

### 不关联（⭐）

#### 1.21.5 后端改动

不影响模组叙事，但影响模组端口——v0.1 开发时需注意 1.21.5+ 的后端改动对 Fabric mod 的兼容性影响。
