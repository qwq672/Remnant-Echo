## 3. 关键生物特性解读

### 3.1 监守者（Warden）

| 原版特性 | 模组叙事解读 |
|----------|--------------|
| 500 血量（最强原版生物） | 监守者是"科研贵族灵魂聚合体"——多个灵魂的能量使其异常强大 |
| 无眼（blind） | 灵魂聚合体无视觉——监守者是被吞噬的科研贵族失去视觉，仅保留听觉 |
| 靠声音狩猎（sonic boom） | 幽匿感知声音的核心机制——监守者是幽匿能量具象，能感知所有声音 |
| 无视护甲的声波攻击 | 声波是维度能量层级——护甲无法防御维度能量 |
| 不可被玩家永久击杀（重生） | 监守者是幽匿能量的聚合，只要幽匿存在，监守者就能重生 |
| 在深暗之域生成 | 深暗之域是幽匿能量最浓集的区域——监守者是幽匿的"守护者" |

### 3.2 末影人（Enderman）

| 原版特性 | 模组叙事解读 |
|----------|--------------|
| 跨维度传送 | 先民维度穿行技术的残留——末影人保留了部分维度穿行能力 |
| 怕水/怕雨 | 维度异化的副作用——末影人的细胞结构在主世界环境中不稳定，水会使其崩解 |
| 怕光（在阳光下燃烧？实际不会） | 实际原版末影人不怕光，但会在阳光下随机传送——模组解读为"主世界强光对末影人维度能量的干扰" |
| 拾取方块 | 殖民军"执行最后命令"的残留行为——曾奉命收集末地资源 |
| 被攻击时集体追击 | 军事防御协议的残留——殖民军曾是集体行动的军队 |
| 掉落末影珍珠 | 末影珍珠是先民维度穿行技术的"残留载体" |
| 被注视时攻击 | 末影人对"被注视"敏感——模组解读为殖民军对"监视"的警惕反应 |

### 3.16 蜘蛛（Spider）与洞穴蜘蛛（Cave Spider）

按 minecraft.wiki + Minecraft Forum + Hypixel Forums 整理：

| 生物 | 原版特性 | 模组叙事解读 |
|------|----------|--------------|
| **蜘蛛** | 中立（白天不攻击）；可在亮光下生成；掉落线+蜘蛛眼 | 蜘蛛是主世界原生生物——非先民遗骨，是维度能量残留的"非人形"具象 |
| **洞穴蜘蛛** | 敌对；只在废弃矿井刷怪笼生成；带毒性（普通难度也中毒）；体型更小；掉落更多蜘蛛眼 | 洞穴蜘蛛是先民实验室的产物——按社区理论"先民在废弃矿井尝试改造蜘蛛，加入毒元素" |

**模组叙事**：
> 「蜘蛛是主世界原生的非人形生物——与苦力怕（生命本源研究副产物）不同，蜘蛛是先民维度能量残留的自然具象，未受人为改造。
>
> 洞穴蜘蛛是先民实验室的产物——废弃矿井的刷怪笼证明洞穴蜘蛛是先民"生物改造"实验的残留，加入毒元素。与流髑（雪原骷髅变种+冰元素）/ Bogged（湿地骷髅变种+毒元素）/焦骸（沙漠骷髅变种+虚弱元素）的"群系+元素"演化路径一致——洞穴蜘蛛是"主世界地下+毒元素"的蜘蛛变种。」

> 「女巫是模组"灾厄村民分支的流浪研究者"——按社区理论（fruitservers.net 将 Witch 归为 Illager Mobs），女巫与掠夺者/卫道士/唤魔者同源，但选择独自研究炼金术而非集体隐修林地府邸。

>
> 女巫的药水知识是先民炼金术的残留——与村民的"炼金古法"同源，但女巫保留了更激进的实验（攻击药水+防御药水），村民只保留温和的酿造。」

### 3.18 灾厄村民家族（Illager Family）

按 minecraft.wiki + minecraft.fandom.com + fruitservers.net + scribd 整理：

| 生物 | 原版特性 | 模组叙事解读 |
|------|----------|--------------|
| **掠夺者** | 用弩；在掠夺者前哨站+raid 生成 | 掠夺者是灾厄村民分支的"前哨士兵"——保留了先民军事组织的外勤传统 |
| **卫道士** | 用铁斧；在林地府邸+raid 生成；默不作声 | 卫道士是灾厄村民分支的"内卫守卫"——铁斧是先民鼎盛期士兵装备的退化版 |
| **唤魔者** | 召唤恼鬼+尖牙攻击；在林地府邸+raid 生成 | 唤魔者是灾厄村民分支的"禁忌生命合成研究者"——召唤恼鬼是其"再造神"实验的残留 |
| **劫掠兽** | 大型野兽；被灾厄村民骑乘；用冲撞攻击 | 劫掠兽是灾厄村民"再造神"实验的产物——试图制造先民守卫的替代品 |
| **恼鬼** | 飞行小生物；被唤魔者召唤；持有铁剑 | 恼鬼是唤魔者"召唤实验"的副产物——灵魂能量被困在小形体中 |

**模组叙事**：
> 「灾厄村民家族是先民中"拒绝接受失败"的分支后裔（按 Minecraft Legends 官方衍生作设定+SyntaxMine 理论）。
>
> 大分裂后，先民后裔分裂为：
> - **村民**：接受失败，退化为普通生活
> - **灾厄村民**：拒绝接受失败，研究禁忌生命合成（恼鬼）与再造神（劫掠兽）
>
> 灾厄村民的"五人组"：
> - 掠夺者=前哨士兵（外勤）
> - 卫道士=内卫守卫（铁斧=先民士兵装备退化版）
> - 唤魔者=禁忌研究者（召唤实验）
> - 劫掠兽=再造神实验（替代先民守卫）
> - 恼鬼=召唤实验副产物（灵魂能量被困）
>
> 女巫被部分社区归为灾厄村民家族（fruitservers.net）——但模组解读为"独自流浪的炼金研究者"，与灾厄村民分支平行而非从属。」

### 3.19 末影螨（Endermite）

| 投掷末影珍珠时生成 | 末影螨是末影人传送的副产物——维度能量具象的小型残留 |
| 攻击末影人时也可能生成 | 末影人受攻击时维度能量泄漏，形成末影螨 |
| 与末影人敌对（末影人会攻击末影螨） | 末影人视末影螨为"维度能量泄漏的耻辱"——殖民军后裔对"能量失控"的警惕 |
| 紫色外观 | 末影螨与末影人同属"维度异化"光谱（紫色） |
| 短暂存在（自动消失） | 末影螨是维度能量的临时具象，能量耗尽后消失 |

**模组叙事**：
> 「末影螨是末影人传送的副产物——维度能量具象的小型残留。这与模组"末影人保留先民维度穿行技术"叙事一致——传送时部分维度能量泄漏，形成末影螨。
>
> 末影人攻击末影螨——殖民军后裔对"能量失控"的警惕。这与模组"先民以为自己能控制灵魂能量，结果发现不能"的悲剧主题呼应。
>
> 末影螨的紫色外观对应模组四色光谱的"维度异化"。」

### 3.20 守卫者（Guardian）与远古守卫者（Elder Guardian）

按 minecraft.wiki + facebook.com 整理：

| 生物 | 原版特性 | 模组叙事解读 |
|------|----------|--------------|
| **守卫者** | 在海底神殿生成；用激光攻击；有尖刺（接触伤害） | 守卫者是先民"水下分支研究站"的防御机械——与潜影贝（末地城防御机械）同源 |
| **远古守卫者** | 每个海底神殿固定 3 个；给予挖掘疲劳；掉落海晶碎片+湿海绵 | 远古守卫者是水下研究站的"指挥官"——3 个对应先民三大研究领域（维度穿行/红石机械/灵魂能量）的水下分支 |

**模组叙事**：
> 「守卫者+远古守卫者是先民在海底神殿（水下分支研究站）的防御机械。
>
> 海底神殿使用海晶石（与紫珀砖/石砖同源但水下变体）——按模组三界同源叙事，海底神殿是先民鼎盛纪元水下分支的研究站。
>
> 远古守卫者固定 3 个——对应先民三大研究领域（维度穿行/红石机械/灵魂能量）的水下分支指挥官。
>
> 远古守卫者的"挖掘疲劳"是先民维度能量的具象——阻止外人接近海底神殿的核心（金块中心+海晶灯）。
>
> 守卫者+远古守卫者与潜影贝（末地城防御机械）同源——都是先民为关键设施设计的"机械守卫"。」

### 3.21 幻翼（Phantom）

按 minecraft.wiki + minecraft.fandom.com + minecraft-magic-and-monsters.fandom 整理：

| 原版特性 | 模组叙事解读 |
|----------|--------------|
| 3 天不睡觉触发不眠机制生成 | 幻翼是"不眠"的具象——先民维度能量对玩家"未休息"状态的反应 |
| 飞行+俯冲攻击 | 幻翼是飞行生物——与恶魂（灵魂飞行）+烈焰人（能量飞行）同源 |
| 不死生物 | 幻翼是不死生物——与僵尸/骷髅同属"维度诅咒"类 |
| 掉落幻影膜 | 幻影膜可用于修复鞘翅——与鞘翅（先民末地殖民军飞行装备）同源 |
| 在阳光下燃烧 | 与僵尸/骷髅同源——维度能量残留在阳光下不稳定 |

**模组叙事**：
> 「幻翼是"不眠"的具象——先民维度能量对玩家"未休息"状态的反应。这与模组"先民维度能量残留无处不在"叙事一致。
>
> 幻翼掉落幻影膜+鞘翅修复——按 MatPat 理论"鞘翅是陨落末影龙的翅膀"（已在 [`15-community-lore/02`](../15-community-lore/02-matpat-game-theory.md) §5 记录），幻翼与末影龙同源，都是"维度能量层级生物"。
>
> 幻翼的不死生物属性——与僵尸/骷髅同属"维度诅咒"类，但幻翼是"飞行不死"——这一独特形态暗示先民曾尝试在主世界培育"飞行守卫"（与铁傀儡=地面守卫对应）。
>
> 幻翼在阳光下燃烧——维度能量残留在阳光下不稳定，与所有不死变体一致。」

### 3.22 蜜蜂（Bee）+美西螈（Axolotl）+海豚（Dolphin）

按 minecraft.wiki 整理：

| 生物 | 原版特性 | 模组叙事解读 |
|----------|----------|--------------|
| **蜜蜂** | 被动；攻击后会在 1 分钟内死亡；可被引诱（花朵） | 蜜蜂是先民"生命本源研究"的温和产物——攻击后会死亡暗示其能量不稳定 |
| **美西螈** | 被动；可攻击 aquatic 敌对生物；可装桶运输 | 美西螈是先民水下研究的副产物——与守卫者同源但被驯化为友好形态 |
| **海豚** | 中立；可用鱼驯服；给玩家速度增益；会引导玩家到沉船 | 海豚是先民水下研究站的"导航员"——保留先民制图传统的退化形态 |

**模组叙事**：
> 「蜜蜂+美西螈+海豚是先民生命本源研究+水下研究的"温和产物"——与苦力怕（失败活化产物）形成对照。
>
> 蜜蜂的"攻击后死亡"暗示其能量不稳定——与嘎枝（生命树脂实验副产物）同源但更温和。
>
> 美西螈可攻击水下敌对生物——是先民驯化的水下防御生物（与铁傀儡=地面守卫对应）。
>
> 海豚的"引导到沉船"——沉船是大分裂期沿海据点失事后的遗存（详见 [`18-overworld-narrative`](../planning/18-overworld-narrative.md) §2.1），海豚保留了先民制图传统，能引导玩家到这些遗存。」
