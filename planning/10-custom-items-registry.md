### 2.1 残破笔记（Tattered Note）

| 属性 | 值 |
|------|-----|
| **物品 ID** | `remnant:tattered_note` |
| **基础物品** | `minecraft:written_book` |
| **L 等级** | L3 |
| **决策日期** | 2026-09-18 |
| **决策者** | 项目方 |
| **状态** | 待实施（v0.1） |

#### 必要性论证

| 候选方案 | 为何不可行 |
|----------|------------|
| L1：纯原版 `written_book` + NBT | ❌ 玩家无法区分普通 written_book 与残破笔记，且 written_book 在讲台上显示不美观 |
| L2：`written_book` + `CustomModelData` | ❌ 实际上这就是 L3 的实现方式（CustomModelData 是 L3 自定义） |
| L3：自定义"残破笔记" | ✅ 必要——通过 `CustomModelData` 提供泛黄、烧焦的视觉差异，但仍保持 `written_book` 的所有行为 |

**结论**：玩家需要视觉提示区分叙事物品与普通书本，L3 是必要的。

#### 关联性论证（满足 4 项）

| 关联维度 | 满足情况 | 说明 |
|----------|----------|------|
| 视觉关联 | ✅ | 纹理基于 `written_book` 纹理修改（加泛黄、烧焦效果），保留书本形状 |
| 行为关联 | ✅ | 行为与 `written_book` 完全一致（可右键阅读、可放入讲台、可复制） |
| 来源关联 | ✅ | 通过原版 loot 表获得（村庄图书馆、沙漠神殿、丛林神庙、废弃矿井、地牢） |
| 数据关联 | ✅ | NBT 结构基于 `written_book`，仅追加 `CustomModelData: 1` |
| 退化关联 | ✅ | 失去模组时退化为普通 `written_book`，玩家仍可阅读 NBT 中的文本 |

#### 退化方案

```python
# 失去模组时的行为
1. 物品 ID 从 `remnant:tattered_note` 退化为 `minecraft:written_book`
2. `CustomModelData` 字段被忽略（原版物品无此字段）
3. `display.Title`、`pages`、`author` NBT 保留
4. 玩家右键仍能阅读完整文本
5. 视觉退化为原版 written_book 纹理
```

#### 实现细节

**NBT 结构**：
```nbt
{
  display: {
    Title: "残破的笔记",
    Lore: ["纸张泛黄，墨迹模糊"]
  },
  CustomModelData: 1,  # 残破笔记的视觉标识
  pages: [
    '{"text":"寻找那座塔。它会告诉你我们是谁。\\n\\n不要相信猪灵。也不要相信我们。\\n\\n—— M."}'
  ],
  author: "M.",
  title: "残破的笔记",
  resolved: 1b
}
```

**纹理文件**：
- `assets/remnant/textures/item/tattered_note.png`
- 基于原版 `written_book` 纹理修改：泛黄 + 烧焦边 + 模糊墨迹

| **决策日期** | 2026-09-18 |

| **状态** | 待实施（v0.1） |
| **详见** | [05-clue-book-system.md](./05-clue-book-system.md) |

#### 必要性论证

| 候选方案 | 为何不可行 |
|----------|------------|
| L1：纯原版 `written_book` | ❌ 无法实现"章节解锁"机制 |
| L2：`written_book` + advancement 树 | ❌ 每个章节一本独立书，玩家背包会有 22+ 本书 |
| L3：Patchouli 的 `guide_book` | ✅ 单一物品承载所有章节，按 advancement 解锁 |

#### 关联性论证（满足 5 项）

| 关联维度 | 满足情况 | 说明 |
|----------|----------|------|
| 视觉关联 | ✅ | Patchouli 的书外观基于原版 `written_book` 纹理 |
| 行为关联 | ✅ | 行为与 `written_book` 一致（右键打开、可放入讲台） |
| 来源关联 | ✅ | 通过原版 advancement 触发解锁 |
| 数据关联 | ✅ | 章节内容存储在 JSON 文件中，结构参考原版 `advancement` JSON |
| 退化关联 | ✅ | 失去 Patchoulli 时，物品退化为普通 `written_book`，玩家无法打开书但物品保留 |

#### 退化方案

```python
# 失去 Patchoulli 模组时的行为
1. 物品 ID 从 `patchouli:guide_book` 退化为 `minecraft:written_book`
2. NBT 中的 `patchouli:book` 字段被忽略
3. 玩家右键无法打开 Patchouli 书界面
4. 物品仍保留在背包中
5. 模组可通过 `tellraw` 降级显示章节文本（通过 advancement reward function）
```

## 4. 决策原则回顾

### 4.1 何时允许 L3 自定义

仅在以下条件**全部满足**时：
1. L1 不可行（无原版物品/方块/机制可承载）
2. L2 不可行（多个原版物品/方块/机制组合也无法实现）
3. 自定义内容满足**至少 2 项**关联性标准（视觉/行为/来源/数据/退化）
4. 提供**退化方案**（失去模组时仍能正常运作）
5. 已记录到本登记表

### 4.2 永远禁止的 L3 自定义

| 禁止项 | 原因 |
|--------|------|
| ❌ 新维度 | 无法与原版维度关联 |
| ❌ 新生物 | 无法与原版生物关联 |
| ❌ 新 Boss（作为新实体） | 必须复用原版 Boss 的 NBT |
| ❌ 新种族 | 无法与原版种族关联 |
| ❌ 新数值系统（如"灵气值"） | 无法与原版机制关联 |
| ❌ 改变原版生物 AI/掉落 | 破坏原版体验 |
| ❌ 新驯服/骑乘机制 | 破坏原版交互 |
