## 🎯 顶层设计原则（最高优先级）

### 原则 0：「补」优先于「添」

本模组的核心原则是**优先补完原版留白**，而非**添加新内容**。所有设计决策必须按以下优先级评估：

#### 三级优先级

```
任何设计提案
    ↓
[Level 1] 能否用原版物品/方块/机制承载？
    ├─ 能 → 用原版实现 ✅
    └─ 否 → 进入 Level 2
    ↓
[Level 2] 能否用原版物品/方块/机制的变体承载？
    ├─ 能 → 用变体实现 ✅（如 written_book + NBT、mossy_stone_bricks + 自定义触发器）
    └─ 否 → 进入 Level 3
    ↓
[Level 3] 必须自定义时，自定义内容是否与原版有关？
    ├─ 是 → 允许自定义 ✅（须满足"原版关联性"判定标准）
    └─ 否 → 提案不通过 ❌
```

#### 「原版关联性」判定标准

任何自定义内容必须**至少满足一项**以下条件：

| 维度 | ✅ 允许自定义 | ❌ 禁止自定义 |
|------|--------------|-------------|
| **物品** | 用原版材质变体（如 `written_book` 改 NBT，或材质基于原版书页纹理衍生） | 完全新材质、新形状、与原版无关的物品 |
| **方块** | 用原版方块变体（如 `mossy_stone_bricks` + 自定义 NBT 标签触发叙事），或基于原版方块材质衍生（如先民石碑用石砖材质 + 雕刻纹理） | 全新方块类型（如"灵魂玻璃"、"虚空水晶"） |
| **结构** | 基于原版结构变体（如在原版废弃矿井基础上**追加**先民储藏室作为变体，使用原版石砖工艺） | 完全独立的新结构（如"亚特兰蒂斯神殿"），或与原版建筑风格冲突的结构 |
| **Boss** | 复用原版 Boss 的 NBT 变体（如末影龙 Phase 自定义、凋灵属性调整） | 全新 Boss 实体（如"先民领袖"、"守门人"作为新生物） |
| **机制** | 基于原版 advancement/loot 表/function 扩展（如自定义 advancement 触发器） | 全新游戏机制（如"灵气值"、"梦境值"、"灵魂能量条"等独立数值系统） |
| **生物** | ❌ 完全禁止 | ❌ 完全禁止 |
| **维度** | ❌ 完全禁止 | ❌ 完全禁止 |

#### 判定示例

| 设计提案 | 判定 | 理由 |
|----------|------|------|
| 用 `written_book` + NBT 承载叙事文本 | ✅ Level 1 | 直接用原版物品 |
| 在原版村庄图书馆 loot 表中追加 `written_book` 条目 | ✅ Level 1 | 直接用原版 loot 表 |
| 在 `mossy_stone_bricks` 上右键触发 `tellraw` 显示铭文 | ✅ Level 2 | 用原版方块 + 自定义触发器 |
| 自定义"先民石碑"方块，材质基于原版石砖 + 雕刻纹理 | ✅ Level 3 | 材质与原版有关（石砖衍生），符合"原版关联性" |
| 自定义"先民储藏室"结构，作为原版废弃矿井的变体追加生成 | ✅ Level 3 | 结构基于原版工艺（石砖、苔石），符合"原版关联性" |
| 自定义"守门人"Boss，作为末影龙的 NBT 变体（调整 Phase 行为） | ✅ Level 3 | 复用原版 Boss，符合"原版关联性" |
| 自定义"灵魂能量"机制作为新数值系统 | ❌ 不通过 | 全新游戏机制，无原版依据 |
| 自定义"虚空水晶"方块作为新材质 | ❌ 不通过 | 完全新材质，无原版关联 |
| 自定义"亚特兰蒂斯神殿"作为独立新结构 | ❌ 不通过 | 完全独立结构，与原版建筑风格冲突 |
| 自定义"光之子"作为新种族 | ❌ 不通过 | 完全新生物，无原版依据 |

### 原则 1：以原版世界观为主

- 所有叙事内容**优先基于原版已有设定**（建筑、生物、物品、Boss）
- 不引入官方未提及的新种族、新文明、新纪元名称（除非作为"对原版留白的解读"）
- 模组的设定本质是**对原版留白的合理串联**，而非**新世界观的创造**
- 若必须自定义设定，该设定必须能在原版资料中找到对应线索

### 原则 2：贴合原版留白逻辑

- 不强行填补官方未解释的内容
- 只做**合理串联**：把原版零散的线索（如凋灵骷髅头颅、远古城市门框、紫珀砖工艺一致）用一条叙事线索串起来
- 留白处继续留白，不强行解释

### 原则 3：碎片化叙事

- 玩家在探索中自行拼凑真相
- 不出现对话、过场、引导箭头
- 叙事文本通过 `written_book`、`advancement` 提示、`tellraw` 命令呈现

### 原则 4：三界同源

- 主世界、下界、末地的建筑与生物源自同一支远古先民文明
- 这一设定通过**串联原版遗迹的石砖工艺一致性**呈现，而非通过新增自定义结构展示

### 原则 5：基于官方衍生作品可参考，但以原版为准

- 可参考《Minecraft: Dungeons》《Minecraft: Legends》等官方衍生作中的设定
- 但以原版为准，衍生作的设定仅作叙事串联的辅助参考
