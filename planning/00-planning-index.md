## 🎯 顶层设计原则（最高优先级）

### 原则 0：「补」不是「添」

本模组的核心原则是**补完原版留白**，而非**添加新内容**。所有设计决策必须先通过以下检查：

| 检查项 | 允许 | 禁止 |
|--------|------|------|
| 新结构 | ❌ 自定义新结构（考古棚、储藏室、祭坛） | ✅ 在原版结构的 loot 表中追加条目 |
| 新物品 | ❌ 自定义新物品（残破笔记、记忆水晶） | ✅ 用 `written_book` / `recovery_compass` 等原版物品承载叙事 |
| 新方块 | ❌ 自定义新方块（古老石碑） | ✅ 复用原版方块（`mossy_stone_bricks`、`infested_stone`），通过 `advancement` 触发器显示文本 |
| 新机制 | ❌ 自定义新机制（认知锁） | ✅ 用原版 `advancement` 触发器实现解锁判定 |
| 新 Boss | ❌ 自定义新 Boss（守门人） | ✅ 复用原版 Boss（末影龙、凋灵、监守者），仅在击杀后触发 advancement 解锁文本 |
| 新生物 | ❌ 完全禁止 | ✅ 完全禁止 |
| 新维度 | ❌ 完全禁止 | ✅ 完全禁止 |
| 新 AI | ❌ 改变原版生物 AI | ✅ 完全禁止 |
| 新交互 | ❌ 新增可驯服/骑乘机制 | ✅ 完全禁止 |

**判定流程**：
```
任何设计提案
    ↓
能否用原版物品/方块/机制承载？
    ├─ 能 → 用原版实现
    └─ 否 → 提案不通过，重新设计
```

### 原则 1：以原版世界观为主

- 所有叙事内容**必须基于原版已有设定**（建筑、生物、物品、Boss）
- 不引入官方未提及的新种族、新文明、新纪元名称（除非作为"对原版留白的解读"）
- 模组的设定本质是**对原版留白的合理串联**，而非**新世界观的创造**

### 原则 2：贴合原版留白逻辑

- 不强行填补官方未解释的内容
- 只做**合理串联**：把原版零散的线索（如凋灵骷髅头颅、远古城市门框、紫珀砖工艺一致）用一条叙事线索串起来
- 留白处继续留白，不强行解释

### 原则 3：碎片化叙事

- 玩家在探索中自行拼凑真相
- 不出现对话、过场、引导箭头
- 叙事文本通过 `written_book`、`advancement` 提示、`tellraw` 命令呈现

### 原则 4：三界同源

- 主世界、下界、末地的建筑与生物源自同一支远古先民文明
- 这一设定**不通过新结构展示**，而是通过**串联原版遗迹的石砖工艺一致性**呈现

### 原则 5：基于官方衍生作品可参考，但以原版为准

- 可参考《Minecraft: Dungeons》《Minecraft: Legends》等官方衍生作中的设定
- 但以原版为准，衍生作的设定仅作叙事串联的辅助参考
