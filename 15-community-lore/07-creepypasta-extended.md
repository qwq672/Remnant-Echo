## 2. "Don't look at the moon"（2021 年新传说）

> 来源：YouTube 转录"Every Minecraft Myth Explained In 13 Minutes"

### 2.1 核心故事

**起源**：2021 年底 Reddit 流传
**核心机制**：
1. 玩家凝视 Minecraft 中的月亮太久
2. 月亮会逐渐变大
3. 月亮颜色变化：黄 → 橙 → 深红 → 纯黑
4. 月亮变黑后，世界开始变化：
   - 白天变暗
   - 天空不再完全变蓝
   - 敌对生物出现在最安全的地方
   - 村庄空无一人
   - 火把不再像以前那样工作
   - 玩家开始听到不属于游戏的声音

### 2.2 社区解释

- 部分玩家认为是 Mojang 在静默更新中加入的隐藏内容
- 部分玩家认为是聪明的 mod
- 实际上是社区创作的 creepypasta，从未在原版游戏中出现

### 2.3 模组叙事关联

- 🟢 **苍白之悔纪元的视觉资源**——"月亮变红/变黑" = 模组"苍白之悔"中"天空异变"的视觉表现
- 🟢 **'听到不属于游戏的声音' = 0 号唱片的氛围**——M. 遗言中的"灵魂低语"
- 🟡 可作为模组"苍白花园"叙事的氛围扩展——玩家进入苍白花园后，月亮逐渐变红

## 3. SCP-4335 "Minecraft 是真实存在的维度"

> 来源：YouTube 转录 + SCP Wiki

### 3.1 核心故事

**SCP-4335 文件内容**：
- Minecraft 不仅仅是一个游戏
- 它是一个"数字门"
- 每次玩家创建一个新世界，他们不是在加载随机代码
- 他们在访问一个真实存在的维度
- 在这个维度里，**Steve 是活的**
- Steve 能感受到每一个动作：
  - 每一个被挖的方块
  - 每一次出拳
  - 每次走入岩浆
- 当 Steve 回应时，不是游戏逻辑，是**疼痛**
- 反复地：
  - 记得被沙砾窒息
  - 记得坠入洞穴
  - 记得在火中燃烧
  - 记得溺水、冻结、饥饿
- Steve 没有重置，只有记忆和重复
- Steve 不是玩家角色
- **Steve 是被困在永无止境游戏中的意识**
- 每次我们登录，我们就在延续这个循环

### 3.2 模组叙事关联

- 🟢 **模组 End Poem 重新解读的核心扩展**——"宇宙由两个灵魂对话创造"中的"两个灵魂"之一可解读为 Steve 的被困意识
- 🟢 **模组"玩家觉醒为继承者"叙事的反向参照**——模组中玩家最终觉醒为"继承者"，与 SCP-4335 中"Steve 是被困意识"形成镜像
- 🟢 **M. 遗言中"你不是第一个，也不是最后一个"的叙事扩展**——M. 知道 Steve 的痛苦，模组可在 0 号唱片中暗示
- 🟡 可作为模组"真结局"的隐喻层——玩家通过 0 号唱片接收 M. 的引导，本质是"打破 Steve 的循环"

### 3.3 注意事项

**这是 SCP 跨界传说，不属于 Minecraft 原版世界观**。模组叙事中可作为"次级权威来源"，不可作为核心叙事依据。

## 4. Enderman = Farlanders（最重要的官方设计史）

> 来源：YouTube 转录 + Notch 2011-07-30 Twitter

### 4.1 官方设计史

**Enderman 的演化路径**：
1. 原始设计：**Farlanders**——高、暗、远距离出现、监视玩家
2. 接近时消失
3. 中立生物，被注视才攻击
4. Notch 觉得太吓人，决定改为"更交互性"
5. 结果：加上传送和搬方块能力 → **Enderman**
6. 保留了"不要看"机制
7. **Farlanders 原本与 Far Lands 直接关联**

> **关键引用**（Notch 2011-07-30 Twitter）：
> "/v/ is petitioning me to change the name from 'Endermen' to 'Farlanders'.
> How about we just rename the 'far lands' to 'the end' instead? ;D"

### 4.2 模组叙事关联

- 🟢 **模组最重要的原版官方证据之一**——末影人最初名为 Farlander，是边境之地的居民
- 🟢 **末影人 = "边境之地的居民" = "虚空之外的虚空的居民"**——模组"末地殖民军异化为末影人"叙事的双重背书（代码层+命名层）
- 🟢 **"被删除部分的游戏的难民"**——模组"大分裂"纪元的视觉表现——末影人是"被删除的天空维度（Sky Dimension）的难民，在虚空中找到新家"

### 4.3 模组叙事建议

**笔记 #25 维度穿行技术报告（晚期版）** 应明确包含：
> "我们曾自称 Farlanders——边境之地的居民。当我们试图穿越虚空，被时间遗弃在末地时，我们的名字也被遗忘。今天，他们叫我们 Enderman。"——E.

## 5. Ravagers = 变异村民

> 来源：YouTube 转录

### 5.1 核心理论

- **Ravagers（劫掠兽）原本是村民**
- 灾厄村民捕获村民并把他们变成 Ravagers
- 用于劫掠
- Ravagers 脸部与村民相似——这是设计上的暗示

### 5.2 模组叙事关联

- 🟢 **模组"灾厄村民"支线叙事的社区理论背书**——S1 灾厄村民叙事中可暗示"Ravager = 被改造的村民"
- 🟢 **模组"苍白之悔"纪元中"生物兵器"叙事的扩展**——监守者+Ravager 都是"被改造的生物兵器"

### 5.3 注意事项

这是社区理论，未得到原版官方确认。模组叙事中可作为"次级权威来源"。

## 6. Giant Alex 详细（2020 年新传说）

> 来源：百度知道 + eathealthy365.com

### 6.1 创作者与版本

- **创作者**：Tolyanich（2020 年）
- **触发条件**：需要 OptiFine 1.12.2 模组
- **本质**：玩家社区创作的 creepypasta，**无法在原版游戏触发**

### 6.2 两种起源说法

1. **变异说**：原本是普通 Alex，在一场角斗中喝下红药水后发生变异，最终变成巨型的恐怖形态
2. **迷雾说**：游荡在 Minecraft 迷雾区域的神秘巨型生物——早期玩家对游戏未探索迷雾区域未知生物的猜测，逐步演化而来

### 6.3 设定

- 高约 12 格
- 皮肤带血色腐烂纹路
- 只会出现在沼泽、森林区域
- 玩家遇见她时会出现视距缩短、天空起雾的异常
- 她会追杀玩家
- 甚至可能导致游戏崩溃

### 6.4 模组叙事关联

- 🟡 **模组"苍白之悔"纪元的视觉扩展**——Giant Alex 的"血色腐烂纹路" = 模组"暗红+白色光谱"叠加
- 🟡 **模组"迷雾区域"叙事**——可作为模组"苍白花园"叙事的早期视觉参考
- 🟡 **模组"末地殖民军"叙事的扩展**——Giant Alex 可作为"被维度异化的先民女性"的视觉暗示

### 6.5 与模组 L1/L2/L3 原则的兼容性

模组**不实装 Giant Alex 作为新生物**——仅作为：
- 告示牌描述中的"传说的怪物"
- 远古城市笔记中 M. 提及的"我们曾试图改造自己，但失败"
- 0 号唱片周边叙事素材

## 7. Mojang 对都市传说的官方态度

> 来源：eathealthy365.com + YouTube 转录

### 7.1 Herobrine 的官方处理

| 时间 | Mojang 处理 |
|------|-------------|
| 2010-08 | 4chan /x/ 板首次出现 Herobrine 帖子 |
| 2010-10 | Copeland 在 Brocraft stream 上演著名的 Herobrine 恶作剧 |
| 2011+ | Notch 反复声明"我没有死去的兄弟，Herobrine 从未在原版游戏中存在" |
| 2011+ | Mojang 在大约 30 个 Java 更新日志中加入"Removed Herobrine"——持续内部笑话 |
| 2026 (26.1) | "Removed baby Herobrine"——最近一次 |
| 持续至今 | 玩家仍声称在单人离线世界中见过 Herobrine |

### 7.2 Mojang 的"承认但不实装"策略

- Herobrine 是 Mojang 唯一"承认但不实装"的都市传说
- 通过"Removed Herobrine"笑话，Mojang 把社区神话变成"内部笑话"
- 这是 Mojang 处理都市传说的标杆——既不否认其文化影响，也不在原版中实装

### 7.3 模组叙事关联

- 🟢 **模组处理都市传说的策略参考**——模组可在更新日志中加入"Removed C."、"Removed M."等内部笑话，致敬 Mojang 的 Herobrine 处理方式
- 🟢 **Herobrine = 模组'苍白之悔'纪元的视觉资源**——空洞眼睛的 Steve = "被先民灵魂离弃的躯体"
- 🟡 模组不实装 Herobrine，但可在某些极罕见遗迹的告示牌中以"H."作为加密代号出现
